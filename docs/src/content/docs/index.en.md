# Design

`@velezanthony/design` turns **a folder of Markdown and one configuration file** into a complete
documentation site on Astro. It is a library, not a site: you install it in your project and it does
the rest.

## What you get

1. **A design system**: palette, typography (IBM Plex), Tailwind tokens, light and dark theme and
   generic components.
2. **A documentation engine**: routes, sidebar, table of contents, search, languages, SEO,
   `sitemap.xml` and a cookie notice, all from your Markdown.

This site is built with the library itself. Why I made it, what I studied from MkDocs Material and
Starlight, and its pros and cons are on the
[project page](https://velezanthony.github.io/proyectos/design/).
